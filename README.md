## 🛠️ System Requirements
To run this application, the following environment is required:
* **Web Server:** Apache (via XAMPP recommended)
* **Language:** PHP
* **Database:** Microsoft SQL Server (MSSQL)
* **Drivers:** Microsoft ODBC Driver for SQL Server

## 🚀 Installation & Setup
1. **Database Setup:** - Execute the SQL scripts provided in the report to create the `vet_clinic` database, tables (`users`, `pets`, `audit_log`), and the restricted user `vet_app_user`.
2. **Application Setup:**
   - Move the **`pawsecure`** folder into your web server's root directory (e.g., `htdocs`).
   - Ensure the database connection settings in `db_connect.php` match your local SQL Server instance.
3. **Run:**
   - Access the application via your browser (e.g., `http://localhost/pawsecure`).
